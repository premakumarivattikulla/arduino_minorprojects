# Arduino Minor Projects

This repository contains two Arduino-based embedded systems projects developed using simulation.

## Projects included
1. Smart Room Temperature Controller with Serial Configuration
2. Traffic Light Controller with Pedestrian Request

## Tools Used
- Arduino Uno
- Tinkercad Circuits
- Arduino C/C++
